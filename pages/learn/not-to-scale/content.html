Why aren't solar system diagrams drawn to scale?

No single diagram can show planet size and orbital distance accurately at the same time. Switch between the two views below to see why — the same eight planets, drawn two honest but incompatible ways.

This is a schematic, top-down camera lens, not an observed planetary configuration or real space mission. Orbit radii use linear AU ratios, but shown planetary phases are arbitrary, paths are drawn circular and foreshortened for perspective, and space/background styling is artistic. Markers are deliberately oversized unless you select true diameters. A physically accurate body may be invisible at this scale. Camera zoom itself changes logarithmically; the underlying distances stay linear. No physical flight time or spacecraft velocity is implied. The original linear size and logarithmic distance comparison below remains available.

Planetary diameters use one linear scale here (Earth = 14 pixels). The gaps between planets are arbitrary, and tiny planets may be only a few pixels wide. Jupiter really is about 11× Earth's diameter.

What's simplified

Even the "distance" view isn't fully honest.

01

Logarithmic, not linear

On a true linear scale, Mercury through Mars would bunch up in the first few pixels and Neptune would be off-screen. The distance view above uses a log scale to keep every planet visible.

02

Orbits aren't circles

Real orbits are ellipses, and this simplification (like most diagrams) treats distance as a single number rather than a range.

03

2D, not 3D

Planets don't orbit in exactly the same plane. This diagram, like almost every solar system diagram, flattens that out.
