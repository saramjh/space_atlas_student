# Grade 4–8 Space Atlas learner usability protocol (not conducted)

State: READY FOR EDUCATOR REVIEW, NOT A COMPLETED STUDY. Software tests cannot prove children understood a scientific explanation or that ads/privacy are appropriate for unsupervised under-13 use.

A teacher or parent must first verify suitable content, privacy, applicable school/guardian consent and ad handling. The current public Privacy page explicitly says child-directed advertising/data controls remain under review. Prefer an ad-free local or institution-approved preview before using the site with students. Do not gather names, precise dates of birth, email addresses, screen/video recordings or free-text identifiable transcripts.

Three supervised predict–interact–explain tasks:
1. Moon Phases: predict the quarter phase; operate the actual phase/orbit controls; explain sunlight versus Earth's shadow.
2. Moon Eclipses: predict whether every new moon produces an eclipse; compare tilted orbital nodes aligned/misaligned; explain why a miss is possible.
3. Choose Transit, Black Holes or Galaxies: predict how a measurable brightness or visible shape changes with one input; use the labeled 2D first, then opt-in 3D if supported; explain what each representation contributes.

With permission, supervising adults may record anonymous categorical outcomes only: predicted without help, corrected after model use, still confused, control not found, or declined/stopped; and non-identifying device width and motion-preference state. Stop if a child is uncomfortable or cannot operate the learning control. Review observed confusion and add source tests before retesting. Do not fabricate participants, scores, quotes or completion results.
