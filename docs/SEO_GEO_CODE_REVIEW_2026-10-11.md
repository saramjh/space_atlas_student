# Space Atlas — Code Smells, Technical SEO and GEO Audit
Date: 2026-10-11 KST. Baseline Git dca30b4. Scope: deployed /solar-system/pluto-dwarf-planet/ and shared static build across 28 public routes. This is a code/HTML/GSC evidence audit, **not** a full accessibility certification or measured ranking uplift.

## Findings and actions
1. **P1 broken metadata attribute quoting (confirmed)**: `build.py` interpolated authored description and OG metadata into quoted HTML attributes unescaped. Pluto's source description includes literal `"planet"`; Python `HTMLParser` and real HTML parsing truncated the `meta[name=description].content` field after "definition of ". Fixed at the shared template rendering boundary using `html.escape(quote=True)` for title, description, canonical, OG title/description/image. No content rewritten. Added 28-page source-to-generated metadata equality gate `ci/verify_seo_metadata.py` to both deploy and read-only site health.
2. **P1 broken scientific source link (confirmed)**: Pluto IAU 2006 press release on `www.iau.org/IAU/Iau/News/PR2006/...` returned redirection to repeated authentication and HTTP 404 in the live HEAD check; even the old `www.iau.org/static/resolutions/Resolution_GA26-5-6.pdf` redirected. Replaced with live accessible International Astronomical Union archive listing `https://iauarchive.eso.org/administration/resolutions/ga2006/` (HTTP 200, lists 2006 planet-definition resolutions and links to the full text). NASA Kuiper Belt link returned HTTP 200. Preserved primary-source status and clear label.
3. **P1 invisible FAQ rich-data (confirmed)**: Three page metadata files included `faq` for black holes, universe scale and Earth seasons, but some structured questions were absent from static visible HTML. Removed their invisible `FAQPage` JSON-LD and obsolete builder branch rather than adding generic FAQ blocks solely for search. Maintained all existing learning text and core `LearningResource`/breadcrumb/collection data. New CI disallows reintroduction of FAQPage without a dedicated visible-content audit.
4. **P2 code-smell duplication (fixed)**: Pluto object classifications and separately maintained neighborhood explanation maps had matching object keys and parallel state logic, creating drift risk. Consolidated into one `facts` table with `planet`, `explanation`, `zone`; SVG <title>/<desc> and the original ARIA linkage remain the accessible description, removed redundant mutable `aria-label` and unused ID. Updated stale regression fixtures for changed source label; preserved keyboard operation and native controls.
5. **P2 Open Graph/content accuracy (open, not silently altered)**: All 28 source page metadata entries share one Unsplash space photograph as OG/Twitter and `LearningResource.image`. It is valid metadata syntax but not page-specific evidence for Pluto, transits and other distinct topics. Avoid asserting better rankings based on this. Prioritize authentically sourced subject-specific previews with credits and availability checks in a separate budgeted media audit, rather than mass replacing with fabricated imagery.
6. **P2 semantic content/inference bounds (protected)**: Pluto SVG icons, ratios and region bands are explicitly illustrative and not orbit maps or body counts; scientific source links and static explanation remain in HTML. This preserves GEO retrieval semantics without falsely presenting diagrams as direct measurement. Do not add `llms.txt` or special AI markup for Google Search as the Google guidance does not require it.
