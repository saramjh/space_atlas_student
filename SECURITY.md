# Security reporting

To initiate a vulnerability report, open [a new issue](https://github.com/saramjh/space_atlas_student/issues/new) titled **Private security contact request**. Include only a generic contact request. **Do not publish exploitation steps, vulnerable URLs with secrets, credentials, student personal information, or other sensitive details in the public issue.**

The maintainer can arrange a private follow-up channel before receiving confidential technical details. This community-maintained educational reference is not a vulnerability-bounty program. Do not access, alter, or expose other visitors' data when reporting.

For general editorial or product feedback, the regular GitHub issue tracker remains available.
